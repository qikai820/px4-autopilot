## 控制修改

保留 `ActuatorEffectivenessVoliroT`、`VoliroTAllocation` 和 MorphQuad 原分配器。增加 `VT_RCT_P_SCALE=0.5`，仅在 `CA_AIRFRAME=17` 且启动时 `VT_CTRL_MODE=1` 的速率控制模块启用。

把原速率环 P 输出先转换为物理力矩，再沿共同旋翼轴 `g=[sin(tilt),0,-cos(tilt)]` 投影：

```text
P_new_Nm = P_old_Nm - (1 - scale) * g * dot(g, P_old_Nm)
```

倾转轴取分配器最终舵机指令，包含固定倾转/故障回退的实际指令。有效指令丢失超过 100 ms 时保留上次有效轴，避免突然恢复高增益；参数更新和显式关闭仍然生效。该角度是指令，不是舵机测量。

- 倾转绝对值不超过 10°，保留原 P 输出。
- 10–30° 平滑过渡；第二版在30°到倒置180°继续使用设定比例。第一版曾在150°之后恢复高 P，这条路径已取消。
- 差动升力方向、pitch 方向、D、积分状态/限幅/方向抗饱和及参考前馈保持原逻辑。
- 按 `VEC_TQ_R/P/Y` 转换到 N·m 后投影，支持不相等的归一化尺度。
- `VT_RCT_P_SCALE=1` 恢复原 P 算术路径，便于同固件 A/B 对比。
- `vector_rate_control_status.reaction_p_scale/reaction_tilt` 记录实际应用的比例和轴。

本次保留 `VT_REACT_FILT=2 Hz`；原生模型对比中，单独降低外环 heading 增益仍有持续振荡，仅降低反扭矩轴 P 已能收敛，因此没有扩大到外环或全部 roll/yaw PID 调参。

## ±160° 扩展中的发现

原参数 `CA_CT_T5RMAX=0.6 N`、`VT_RCT_P_SCALE=0.5` 在原生模型倒置段失败。板上正常完成 +60°、+90° 悬停，但进入 +120° 时角速度越限，中止后的恢复/降落过程仍失稳，最终触发螺旋桨不平衡失效保护（ULog 中 `fd_imbalanced_prop` 与 Termination 同时出现），仿真状态随后无效。绝对 roll/pitch 失效标志更早已在合法的大角度段出现，但不能把最终 Termination 简单归因于这两个阈值。已保存该失败日志 `hil/extended-positive/03_19_46.ulg`，随后对 HIL 强制上锁并重启恢复。该轮不是大角度验收通过。

- `FD_FAIL_R/P=60°` 是绝对欧拉角失效阈值，不能直接用于倒置目标；后续仅在 HIL 试验期间设为0，保留测试脚本的四元数误差、机体角速度、有限值/新鲜度守卫，测试结束恢复60°。
- `CA_CT_T5RMAX` 单位是 N，不是反向推力比例。当前 native 模型在静态、约100 ft高度的尾电机满指令输出约 +27.97 N / −18.56 N，反向/正向比例约0.664；原配置10 N /0.6 N的比例为0.06，明显不匹配。
- 保留正向10 N归一化标度，仅将反向设为6.6 N做参数对比，倒置响应明显改善。这是用于隔离归一化不匹配的 HIL/主机试验值，**不是该电机实机反推能力的标定值**。
- `VT_RCT_P_SCALE=0.5`、反向6.6 N的原生 +160° 仍有0.223°姿态 RMS、1.653°/s角速度 RMS，未通过原生阈值；比例0.4时，19个角度（0、±15、±30、±45、±60、±90、±120、±135、±150、±160°）全部通过原阈值。±160°姿态 RMS分别为0.003°/0.007°，角速度 RMS为0.016/0.040°/s。
- 扩展测试修正了测试夹具的执行器预热：`SuspendIntegration()` 会把 dt 置零，不能预热电机状态；现改为 `SetHoldDown(true)` 固定机体、保留非零 dt。此项只影响主机测试，不改变飞控固件或分配器。
- 恢复模型时发现板端 `voliro_t.xml` 已与测试前快照不同：惯量/起落架被改动，前桨推力/旋转反作用模块和阻力模块被移除，重新加载报 `isolated-thrust-lbf[0]` 不存在。用户确认仅主动把 Ixx 从0.28改为0.26，不能把其余差异归因于用户操作。该文件已保留；独立 `voliro_hil_20261113_160` 试验模型保留 Ixx=0.26，其余 XML 使用完整快照，同时复制原模型的初始化、积分器与风场运行配置。

原生完整结果分别在 `native-160-warm`（原参数失败）、`native-160-rmax6.6`（0.5端点未达标）和 `native-160-rmax6.6-p0.4`（通过）。不得把主机参数对比直接写成板载 ±160° 已通过。
