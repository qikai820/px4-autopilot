# Voliro T 五电机矢量控制用户使用说明

本文适用于本项目自定义的 `19003_voliro_t` 机架、CUAV 7 Nano 固件以及配套 JSBSim HIL。它是四个前电机共用倾转舵机、一个可正反转尾电机的方案，不代表商业 Voliro T 的原厂配置。本文依据当前工作区源码编写，其中部分实现和默认值尚未提交；实际设备以其烧录固件、参数和加载的模型为准。

## 1. 使用前理解

前电机 M1/M2 位于机体右侧，M3/M4 位于左侧；M5 位于机尾，提供俯仰力矩。四个前电机共同倾转，机体无法独立产生横向侧推，横向运动需要机体滚转。控制链为 `vector_pos_control`、`vector_att_control`、`vector_rate_control` 和 Voliro T 控制分配器。位置、姿态及角速度参数分别主要使用 `VPC_*` 和 `VC_*` 参数族，任务速度、起降约束仍使用 `MPC_*`。不要把旧 `GC_*`、`GPC_*`、`GAC_*` 控制器参数直接当成新控制器参数。

参数文件中的 `param set-default` 只设置默认值：**已有保存值优先，升级固件、重启或选择机架不保证覆盖旧参数。** 在 QGroundControl 参数页检查实际值，或在 MAVLink 控制台使用 `param show 参数名`。修改前导出完整参数备份；保存时以实际设备是否成功回读为准。

坐标约定：机体 FRD 中 X 向前、Y 向右、Z 向下；位置力臂从整机重心测量，单位为米。飞行器不同装配、桨、动力和重心需要重新测量，本文数值只是当前配置的起始示例。

## 2. 选择机架与控制链

1. 在 QGroundControl 选择 `19003 Voliro T`，或者确认已有 `SYS_AUTOSTART=19003`；按系统提示重启。
2. 确认 `CA_AIRFRAME=17`，同时确认运行 `vector_*` 控制链。不要同时启动同职责的 `mc_*` 或旧 `geo_*` 控制模块。
3. 核对电机、舵机输出功能、传感器方向、遥控器和故障保护。固件编译成功不能替代 HIL、台架或飞行验证。

## 3. 几何、动力与倾转参数

表中的“示例值”来自当前 19003 初始化脚本，并非设备实时读数。

| 参数 | 示例值及单位 | 含义与设置方法 |
| --- | --- | --- |
| `CA_CT_X` | 0.14 m | 重心到前电机连线的前向距离。改变重心后重新测量。 |
| `CA_CT_Y` | 0.45 m | 前电机左右半跨，左、右电机中心横向间距的一半。 |
| `CA_CT_Z` | 0 m | 前电机相对重心的机体 Z 坐标，向下为正。 |
| `CA_CT_TAIL` | 0.64 m | 重心到尾电机的后向水平距离；本例前后电机线相距 0.78 m，故为 0.78−0.14。 |
| `CA_CT_TMAX` | 39.5 N | 分配器使用的**单个前电机**最大推力参考；应按安装后的桨、电机、电调和同轴影响标定。 |
| `CA_CT_T5MAX` | 10 N | 分配器使用的尾电机最大推力参考；当前分配器使用对称正反推力参考，实际反向推力可能不同。 |
| `CA_CT_KM` | 0.02 m | 前电机反扭矩与推力的比例系数；影响偏航力矩估算。 |
| `CA_CT_ANGLE` | 120° | 共倾转机构的对称软件角度限幅，也是归一化舵机指令换算角度的比例；不是机体姿态限幅。必须与舵机实际行程、PWM 标定及 JSBSim 映射一致。 |
| `CA_CT_RATE` | 90°/s | 共倾转指令的角速度限幅；归零时也受该限制。不能替代舵机实际速度测量。 |
| `CA_R_REV` | 16 | 电机可逆位掩码；16 为第 5 电机对应位。电调也必须正确配置可逆模式。 |
| `CA_AIRFRAME` | 17 | 选择本项目 Voliro T 分配器。 |
| `CA_METHOD` | 0 | 当前机架使用的控制分配方法配置，具体适用范围以固件元数据为准。 |

分配器的归一化总推力参考为 `4 × CA_CT_TMAX + CA_CT_T5MAX`。不能简单把 `MPC_THR_HOVER` 等同于单电机油门；推力曲线、尾电机分担和模型映射都会影响悬停。改变推力参考后应重新验证悬停推力及控制效果。

## 4. M5 尾电机保护

以下阈值作用于推力经平方根换算后的**归一化电机指令**，不是推力百分比。保护针对控制分配输出，不拦截直接执行的 actuator test。

| 参数 | 示例值 | 说明 |
| --- | --- | --- |
| `CA_R5_SLEW` | 0.40 s | 尾电机指令从 −1 到 +1 的完整变化最短时间；保护内部应用一次，不应理解为转子停止时间。 |
| `CA_CT_T5_DZ` | 0.03 | 指令绝对值低于该阈值时目标为零，现有输出按速率限制下降；0 关闭该死区。 |
| `CA_CT_T5_HYST` | 0.10 | 从停止状态启动或请求反转需要达到的指令阈值；有效阈值不低于死区。 |
| `CA_CT_T5_HOLD` | 0.04 s | 反向需求须持续满足阈值的确认时间；旧方向先降至零，短暂反向请求不会启动反转。0 取消确认时长。 |
| `CA_CT_T5_WAIT` | 0.08 s | 输出到达精确零指令后，启动反向前的零指令等待时间。0 取消定时等待，但仍要求经过零指令样本。 |

零指令等待不等于已检测到电机停转。电调支持的 3D 模式、中立值、死区、方向和停转时间必须通过实际动力系统检查。保护不检测温度、电流和转速。当前阈值是台架起点，不是已标定的硬件安全值。

按示例质量 5.04 kg、前后力臂 0.14/0.64 m 估算，静态悬停尾部需要约 8.87 N，接近示例 10 N 上限；真实推力余量、反向推力、热能力及动态响应必须实测。

## 5. 姿态、速度与遥控参数

| 参数 | 示例值 | 用途 |
| --- | --- | --- |
| `VEC_TQ_R` / `VEC_TQ_P` / `VEC_TQ_Y` | 各 10 N·m | 滚转、俯仰、偏航归一化力矩指令 1 所对应的物理力矩参考；不是任何工况下都能达到的实际力矩。与 `VC_*` 角速度控制增益一起理解和整定。 |
| `VEC_GYRO_FF` | 0 | 角速度耦合前馈开关。启用前需校准惯量和力矩参考。 |
| `VEC_IXX` / `VEC_IYY` / `VEC_IZZ` | 0.1 / 0.1 / 0.2 kg·m² | 可选角速度耦合前馈所用的机体惯量；是参数默认值，不代表已测惯量。 |
| `VEC_AUX_ATT` | 1 | 启用独立辅助姿态输入；在 Voliro T 支持的手动位置模式中，AUX1 控制机体俯仰。 |
| `RC_MAP_AUX1` | 按遥控器设置 | 将校准好的遥控通道映射到 AUX1；未映射不能使用该功能。 |
| `VT_PITCH_MAX` | 10° | AUX1 机体俯仰目标限幅，还可能被当前姿态倾角限制进一步约束；不是机械舵机角限幅。 |
| `VT_PITCH_RATE` | 20°/s | AUX1 机体俯仰目标变化速率，不等于 `CA_CT_RATE`。 |
| `MPC_MAN_TILT_MAX` / `MPC_TILTMAX_AIR` | 20° / 20° | 手动和空中任务相关的机体倾斜限制；按实际控制模式生效。 |
| `MPC_THR_HOVER` | 0.292 | 归一化悬停推力参考；应依据匹配模型或真实动力重新校准，错误值会影响高度控制及着陆检测。 |
| `MPC_USE_HTE` | 0 | 当前 vector 默认关闭悬停推力估计器，使用配置的悬停推力参考。 |
| `MPC_XY_VEL_MAX` / `MPC_VEL_MANUAL` / `MPC_XY_CRUISE` | 各 2 m/s | 分别限制水平速度、手动速度和任务巡航速度。 |
| `MPC_Z_VEL_MAX_UP` / `MPC_Z_VEL_MAX_DN` | 各 1 m/s | 最大上升、下降速度。 |
| `MPC_Z_V_AUTO_UP` / `MPC_Z_V_AUTO_DN` | 各 1 m/s | 自动模式上升、下降速度约束。 |
| `MPC_ACC_HOR` / `MPC_ACC_HOR_MAX` | 各 2 m/s² | 水平加速度相关限制。 |
| `MPC_ACC_UP_MAX` / `MPC_ACC_DOWN_MAX` | 各 1 m/s² | 上升、下降方向加速度限制。 |

AUX1 俯仰功能面向 Position、Position Slow、Hold 等支持的手动位置控制入口，自动任务和 Offboard 不应假定响应 AUX1。开关、通道有效性、实际模式和参数以运行日志为准。

## 6. 输出连接与标定

当前 CUAV 7 Nano 示例：

| 输出功能 | 默认功能值 | 用途 |
| --- | --- | --- |
| `PWM_MAIN_FUNC1`～`PWM_MAIN_FUNC4` | 101～104 | M1～M4 前电机 |
| `PWM_MAIN_FUNC5` | 105 | M5 可逆尾电机 |
| `PWM_MAIN_FUNC6` | 0 | 未分配 |
| `PWM_MAIN_FUNC7` | 201 | 共倾转 Servo 1 |
| `PWM_MAIN_TIM0` / `PWM_MAIN_TIM1` | −5 / −5 | 示例使用 DShot150；电调必须支持相应协议。 |
| `PWM_MAIN_TIM2` | 50 Hz | MAIN7/8 所在定时器的示例舵机 PWM 频率。 |

MAIN5/6 共用定时器；当前示例将 M5 放在 MAIN5，舵机放在 MAIN7，以避免同一组同时配置 DShot 和普通 PWM。接线和定时器功能以实际板型和固件为准。查看 `DSHOT_3D_ENABLE`、`DSHOT_3D_DEAD_L`、`DSHOT_3D_DEAD_H` 等电调相关参数的固件说明，结合实际电调完成可逆模式与中立值标定，不能仅依靠 `CA_R_REV`。

从机体上方向下看、机头朝前，源码中的前电机旋向为 M1 逆时针、M2 顺时针、M3 顺时针、M4 逆时针。电机编号、桨旋向、ESC 输出和推力方向须逐项核对。使用 actuator test 前拆卸桨叶：直接电机测试不经过上述 M5 保护。对舵机检查中位、正负方向、端点、实际角度及机械限位；归一化舵机命令 0 表示中位，不表示无 PWM。

## 7. JSBSim HIL 配置与切换

HIL 输出通过 `HIL_ACT_*` 功能映射，与物理 `PWM_MAIN_*` 独立。当前默认 `HIL_ACT_FUNC1`～`HIL_ACT_FUNC5` 为 101～105，`HIL_ACT_FUNC6=201`。检查仿真模型接收顺序、归一化范围、舵机中位及正负方向。`SYS_HITL` 的实际模式和是否同时驱动物理输出取决于当前固件；不要把一次日志中 `SYS_HITL=3` 的行为推广到其他构建。

此次 2026-10-30 HIL 起飞日志中，`SENS_BOARD_ROT=6`（偏航 270°）作用于已按机体系输出的仿真 IMU，使滚转与俯仰反馈串轴。**对于该次使用的模型和固件，HIL 应将 `SENS_BOARD_ROT` 设为 0；恢复真机前须重新设回与实物安装一致的方向，该次真机配置为 6。** 不同仿真模型若输出传感器安装坐标系，应先核对接口，不要盲目套用。

该次 MCAP 确认模型重心对应前、尾力臂 0.14/0.64 m，而 PX4 当时保存了 0.04/0.74 m；模型以 120° 缩放舵机指令，而 PX4 当时为 60°。对**该次匹配模型**，可在解除武装后检查并设置：

```sh
param set SENS_BOARD_ROT 0
param set CA_CT_X 0.14
param set CA_CT_TAIL 0.64
param set CA_CT_ANGLE 120
param save
```

设置后重启飞控，重置/重新加载仿真模型，并重新回读参数和模型。若改为其他模型、舵机缩放或真机，必须重新核对对应参数；120° 是当前模型缩放值，并非所有机械机构都允许的真实行程。不要把仿真传感器方向配置直接带回真机。

## 8. 推荐操作流程

1. **准备**：确认固件版本、已保存参数、机架编号及 JSBSim 模型版本；备份参数。检查质量、重心、推力曲线、舵机角度比例和电机顺序是否匹配。
2. **无桨台架**：确认遥控器与模式切换、IMU 方向、每个输出编号、电机方向、M5 中立及正反转、舵机中位和限位。测试 actuator test 时不要依赖 M5 软件保护。
3. **HIL**：确认仿真 IMU 坐标系、`SENS_BOARD_ROT`、`HIL_ACT_*`、推力和倾转比例。先检查静止姿态，再进行受控的起飞和短时悬停；监视姿态、角速度、推力和分配残差。
4. **逐步验证**：在悬停稳定后，再逐步验证位置、AUX1 俯仰、任务、接管、返航和降落。验证每项功能的实际日志，不用软件编译或主机测试结果替代。
5. **切回实物**：恢复并回读真实传感器安装方向，核对实物参数、输出及故障保护；推力、惯量、反转停机时间和增益须有相应实测依据。

## 9. 常见问题与日志

- **刚起飞就翻转**：检查 IMU 坐标、`SENS_BOARD_ROT`、电机映射、左右推力和舵机方向；对照 JSBSim 真实角速度与 `vehicle_angular_velocity.xyz`，不要只看姿态动画。
- **俯仰无法跟踪或尾电机长期饱和**：检查重心、`CA_CT_X`、`CA_CT_TAIL`、尾电机推力和反向效率；查看 `actuator_motors.control[4]` 与 `control_allocator_status.unallocated_torque[1]`。
- **倾转角度不符**：比较 `actuator_servos.control[0]`、`CA_CT_ANGLE`、模型输入比例和实测舵机角度；同时检查方向、PWM 中位和端点。
- **空中误判着陆或高度参考突变**：检查 `MPC_THR_HOVER`、最小推力、悬停推力曲线和 `vehicle_land_detected`；相对高度还依赖 Home。不要仅凭 QGC 相对高度判断模型真实高度。
- **参数改了但行为没变**：回读参数、确认修改对象及固件版本，检查是否需要重启，以及是否仍使用旧参数库或旧模型。核对参数保存和 SD 介质状态。

推荐记录 `vehicle_attitude`、`vehicle_attitude_setpoint`、`vehicle_angular_velocity`、`vehicle_rates_setpoint`、`vehicle_torque_setpoint`、`vehicle_thrust_setpoint`、`actuator_motors`、`actuator_servos`、`control_allocator_status`、`vehicle_local_position`、`vehicle_land_detected` 和模式/故障事件；HIL 同时保存包含模型状态的 MCAP。查看分配残差时，分配器基于配置的模型计算，不等同于推力传感器实测值。
